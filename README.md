# نظام غياب ومتابعة — كنيسة أبي سيفين والأمير تادرس بطنطا

تطبيق PWA يعمل على GitHub Pages.

- `index.html` — نظام الغياب
- `admin.html` — لوحة المشرفين
- `library.html` — المكتبة الروحية
- `manifest.json` / `sw.js` / `icons/` — ملفات الـ PWA

## بعد النشر
افتح الرابط من الهاتف ← «تثبيت التطبيق» (أندرويد) أو «إضافة إلى الشاشة الرئيسية» (آيفون).

## عند تعديل أي ملف
غيّر رقم `VERSION` في أول ملف `sw.js` (مثل `v2` ← `v3`) ليصل التحديث للمستخدمين.
